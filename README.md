# BROADWING

## Локальний перегляд

Розпакуйте архів і відкрийте `public/index.html` у браузері. Для перегляду через локальний сервер виконайте з кореня проєкту `python -m http.server 8000 --directory public` і відкрийте `http://localhost:8000`.

## Публікація у Vercel

Завантажте вміст архіву до Git-репозиторію та імпортуйте його у Vercel. Виберіть коренем проєкту папку з `vercel.json` і натисніть **Deploy**. Конфігурація запускає `node build.mjs` і публікує папку `dist`. Під час збірки адреси для поширення посилань формуються з домену розгортання.

## Форма звернення

Для приймання заявок вкажіть адресу свого обробника в полі `endpoint` файлу `public/form-config.js`. Поки поле порожнє, форма пропонує зв’язатися телефоном.

Обробник отримує POST-запит у форматі JSON із заголовком `Idempotency-Key`. Після прийняття заявки він має відповісти статусом 2xx і повернути `{"accepted": true, "requestId": "…"}` з фактичним ідентифікатором заявки.
